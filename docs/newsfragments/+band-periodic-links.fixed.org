A periodic atomic band now keeps each neighbour-link image shift
continuous between steps using =minimage='s Euclidean displacement
instead of rewrapping the link from scratch on every assembly.
Slabs and wires use the same rank-aware convention, and position
replacement by zoom, RTR, or min-mode refinement refreshes the shifts.
This avoids force sign flips at half-cell cuts and keeps host-wrapped
handoffs and skewed links on the same physical image.
