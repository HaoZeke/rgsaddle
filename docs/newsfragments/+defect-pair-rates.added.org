=defect_pair_rates= searches a caller-supplied hop catalogue with the solid-state dimer, requires one negative mode, and checks that a push off both sides of the saddle returns to the named minima. A fixed climbing-image band is started from an IDPP path through that saddle. PAFI integrates =⟨(∇E · n)(1-ψ)⟩= (Swinburne and Marinica, Phys. Rev. Lett. 120, 135503 (2018), doi:10.1103/PhysRevLett.120.135503). The rate is =κ ν exp(-ΔF/kT)=, with =ν= the reactant curvature along the path tangent and =κ= the Bennett–Chandler factor (Chandler, J. Chem. Phys. 68, 2959 (1978), doi:10.1063/1.436049). The Vineyard rate is stored beside it. =RateCatalogue= is =rgsaddle.defect_pair_rates= version 1. =howto/defect-pair-rates=.
The climbing image is armed only after a plain relaxation of the band. L-BFGS follows the highest image, so a path that still contains a collision climbs the collision; the NEB guards drop that step and do not remove it. A diverging climb is repeated with FIRE, or with ODE12r when the caller was already on FIRE. The connectivity push is the largest atomic displacement. PAFI block errors use the integrated autocorrelation time, and a finite-temperature rate is stored only when the zero-temperature integral of the path force reproduces the static barrier.
