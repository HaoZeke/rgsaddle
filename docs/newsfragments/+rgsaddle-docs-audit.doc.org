The rustdoc of the band, stencil, dimer, P-RFO, IRC, IDPP, OH-TST and index-k modules is audited. Public items state their units (eV, Å, fs), array shapes and order, errors and panics, and cite the method papers by DOI. Windows, force tolerances and eigensolver subspace sizes whose docs disagreed with the code are corrected. Top-level entry points gain runnable examples on analytic surfaces, and the C entry points for index-k, quick-min and solid-state bands document their status codes and buffer layouts.
