* Added an adaptive OH-TST hyperplane string with shared constrained samples,
  a correlated pilot whose stride doubles until the autocorrelation time fits
  fourteen records, production-resolution relaxation, and a finite-temperature
  profile whose geometry and quadrature errors are measured. The offset
  quadrature gap stops at the dividing plane. `TargetMet` requires the
  combined error. `SampleCap` is the record cap with that combined target
  still unmet, including when the sample itself is already precise.
  `Unresolved` is the same split below the cap.
  Correlation-width batching is shared by every engine-backed hyperplane
  sample, so it can change reported standard errors outside the adaptive
  string as well. An odd tail is dropped so every block has the same width.
  The effective-sample floor is the block count that caller passed, 20 for
  a plane or thermodynamic integration and 5 for PAFI.
  Symmetry
  multiplicity is `with_region` once inside the estimator; the caller adds
  `with_paths` and does not call `with_region` again. Rotating bounded planes
  remain an explicit error until wall-contact derivatives are available.
