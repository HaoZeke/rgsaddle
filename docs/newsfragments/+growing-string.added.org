~GrowingStringSession~, ~GrowingStringConfig~, ~GrowingStringPhase~, ~GrowingStringReport~, and ~StringSession~ implement the growing string method of Peters, Heyden, Bell, and Chakraborty, J. Chem. Phys. 120, 7877 (2004), doi:10.1063/1.1691018, with hand-off upon join to the simplified string method of E, Ren, and Vanden-Eijnden, J. Chem. Phys. 126, 164103 (2007), doi:10.1063/1.2720838.
Reactant and product fragments relax separately under frontier tangent constraints and advance inward according to a configurable node-add criterion (~frontier_tol~, ~min_steps_per_node~, ~max_steps_per_node~, ~join_tol~) while preserving stable ~ImageId~s and batched calculator evaluations.
C ABI minor 43 adds ~rgsaddle_growing_string_*~ (~rgsaddle::GrowingString~ in C++), and Python adds ~rgsaddle.GrowingString~ and ~rgsaddle.ase.GrowingString~.
