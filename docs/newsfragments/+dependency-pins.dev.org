~ci/check_dependency_pins.py~ fails when a git dependency names a tag, a branch or a short rev, or asks for anything but the exact version at its rev.
It also fails when ~cargo tree -d~ lists a second copy of rgsaddle, rgmin, linkcell, minimage, eindir-core, rgpot-core, dlpk, readcon-core, readcon-db or any git crate.
It runs on this crate with all features and on ~ci/consumer~, a dependent that pins linkcell, rgmin and rgpot-core by full rev.
The CI test job runs it and compiles that consumer.
